# Mohammed Kaleem Uddin — Data Analyst Portfolio

A production-oriented Next.js portfolio starter based on the supplied creative/UX brief.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before launch

1. Replace `public/resume.pdf` with the real PDF.
2. Replace the placeholder email and social URLs in `app/page.tsx`.
3. Replace editable experience/project text with verified facts.
4. Connect the contact form to an email/backend provider.
5. Add real project screenshots/artifacts when available.
6. Add analytics only after choosing a privacy-conscious provider.

## Design system

Warm Ivory `#F4F0E8`, Soft Paper `#FAF8F3`, Ink `#171715`, Stone `#A6A097`,
Dusty Sage `#829486`, Muted Terracotta `#B77D68`, Faded Butter `#D8C98B`.

The site uses an editorial serif + mono/data typography pairing, a restrained WebGL data field,
smooth scrolling, responsive layouts, keyboard-visible controls and reduced-motion fallbacks.

The supplied brief explicitly requires truthful/editable content and no fabricated achievements or metrics.
